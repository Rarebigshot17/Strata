The Strata engine keeps every routed expert of a mixture-of-experts model in system RAM and caches the experts it uses most often in VRAM. When a token arrives, the router picks eight of the 288 experts in each layer, and the engine computes the cached ones on the GPU and the rest on the CPU.

def kda_step(state, q, k, v, beta, log_decay):
    # One token of Kimi Delta Attention for one head.
    state = state * log_decay.exp()[:, None]
    state = state + beta * (k[:, None] * (v - k @ state)[None, :])
    return state, q @ state
